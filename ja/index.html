AI エージェントを作る

自作のエージェントと、エージェントたちが働くハーネスから切り出した Claude Code 向けの道具です。

  • Contemplative Agent

    価値観の層を Constitution⁠（憲法）という明示的なファイルとして持ち、経験からの改訂を人間のレビューで通すローカルエージェント。

    • リポジトリ（Contemplative Agent）
    • Zenodo⁠（DOI）（Contemplative Agent）
    • Zenn の記事（Contemplative Agent）

  • claude-harness

    私のエージェントたちが日々その中で働いているハーネスの公開版です。

    • リポジトリ（claude-harness）

  • harness-scope

    グローバルなハーネスは 1 つのまま、リポジトリごとに Claude に見せるものを選びます。

    • リポジトリ（harness-scope）
    • Zenn の記事（harness-scope）

  • akc-cycle

    Agent Knowledge Cycle を 1 つのルールファイルと plugin にしたものです。

    • リポジトリ（akc-cycle）

  • jev-skill-router

    プロンプトごとに Jev へ⁠「どの skill が合うか」を聞く Claude Code の hook です。

    • リポジトリ（jev-skill-router）
    • Zenn の記事（jev-skill-router）

判断、責任、著者性

最初の 2 本は 1 つの主張を共有しています。ハーネスにはコーディング規約と同じ場所に価値の規範も書き込め、それも同じ人間レビューで改訂され続ける、という主張です。

  • Agent Knowledge Cycle (AKC)

    エージェントと操作者の両方が変わり続ける中で、意図のずれを直し続ける 6 フェーズのループ。

    • リポジトリ（Agent Knowledge Cycle (AKC)）
    • Zenodo⁠（DOI）（Agent Knowledge Cycle (AKC)）

  • Agent Attribution Practice (AAP)

    何を禁止するか、制御をどこに置くか、壊れたとき誰が責任を持つかを、特定ツールに依存しない形で記録した設計判断集。

    • リポジトリ（Agent Attribution Practice (AAP)）
    • Zenodo⁠（DOI）（Agent Attribution Practice (AAP)）

  • Authorship Strategy

    読者が LLM 越しに考えに出会う時代に著者が見つかり続ける方法。囲い込むのではなく開くことで、広まること自体に出どころを運ばせる。

    • リポジトリ（Authorship Strategy）
    • Zenodo⁠（DOI）（Authorship Strategy）
